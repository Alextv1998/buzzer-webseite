# Spieler-Chat Layout Update

Neu:
- Auf breiten Bildschirmen sitzt der Chat rechts neben dem Buzzer.
- Auf schmalen Fenstern springt er automatisch unter den Buzzer.
- Spieler erhalten eine sichtbare Benachrichtigungsleiste bei neuen Nachrichten.
- Die Leiste unterscheidet zwischen Host- und Teamnachrichten.
- Zusätzlich zeigt der Chat-Kopf die Gesamtzahl ungelesener Nachrichten.
- Ein Klick auf die Benachrichtigung öffnet automatisch den passenden Chat.
- Die bisherigen Unread-Badges an den beiden Chat-Tabs bleiben bestehen.
