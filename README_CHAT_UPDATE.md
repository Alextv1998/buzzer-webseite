# #Musiklex Buzzer – Chat-System Update

Neu eingebaut:

- Privatchat zwischen jedem Spieler und dem Host
- Teamchat für Spieler desselben Teams + Host
- Kein öffentlicher Alle-Chat
- Chat-Zentrale im Host-Dashboard
- Neue-Nachrichten-Badges
- Antwortmodus für geheime Antworten an den Host
- Zeitstempel bei jeder Nachricht
- Privatchat und Teamchat separat sperrbar
- Einzelne Chatverläufe löschbar
- Spieler-Chat einklappbar
- Teamchat wird automatisch anhand der Teamzuordnung angezeigt

Die bestehenden Buzzer-, Team-, Punkte-, Layout-, Tab-, Host-Login- und Kick-Funktionen wurden als Basis beibehalten.
