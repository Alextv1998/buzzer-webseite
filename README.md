# Online Buzzer

## Lokal starten
1. Node.js installieren.
2. In diesem Ordner ein Terminal öffnen.
3. `npm install`
4. `npm start`
5. Im Browser `http://localhost:3000` öffnen.

Damit andere Personen im Internet mitbuzzern können, muss die App auf einem Server gehostet werden, z. B. Render oder Railway.

## Funktionen
- Spielername eingeben
- Live-Buzzer über Socket.IO
- Host kann Runde starten, sperren und zurücksetzen
- Buzz-Reihenfolge
- Reaktionszeit in Millisekunden
- Abstand zum schnellsten Spieler
- Anzeige verbundener Spieler
